# Метро-таймер: Київ

iOS-приложение: отсчёт до своей станции киевского метро на экране блокировки и в
Dynamic Island — без GPS, сети и фоновых режимов. В App Store с 27.08.2026:
id6804173309, bundle `ua.vlad.MetroTimer`, команда `JC2G64UQ8N`. SwiftUI, iOS 16.1+,
без внешних зависимостей.

Сайт (лендинг, политика конфиденциальности, поддержка) — соседний репозиторий
`dayvan777/METRO` в `../METRO`: GitHub Pages, домен metrotimer.app.

## Сборка и тесты

```bash
xcodebuild -project MetroTimer.xcodeproj -scheme MetroTimer \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro Max' test
```

Тесты работают в процессе приложения и читают настоящий `kyiv_metro.json`.
Имена симуляторов меняются с версиями Xcode: `xcrun simctl list devices available`.
Тесты, сверяющие тексты, фиксируют `appLanguage = .uk` в `setUp` — новый симулятор
по умолчанию английский.

## Правила

- **Проект генерируется.** Добавил или удалил файл — поправь списки в начале
  `Scripts/gen_pbxproj.py` и запусти `python3 Scripts/gen_pbxproj.py`.
  `project.pbxproj` руками не править.
- **Номер сборки** генератор сохраняет из текущего `project.pbxproj`. Перед каждой
  загрузкой в App Store Connect поднимать явно: `MT_BUILD=<следующий> python3
  Scripts/gen_pbxproj.py`. Версия витрины — `MARKETING_VERSION` в том же скрипте.
- `Shared/` и `kyiv_metro.json` входят и в приложение, и в виджет: без JSON
  `MetroRepository.init` падает намеренно.
- **Тексты — только парами** `tr("українською", "in English")` в `Shared/Strings.swift`.
  Файлов `.strings` нет, кроме `InfoPlist.strings`.
- **Политика конфиденциальности** живёт в трёх местах и должна совпадать:
  `AppStore/PRIVACY.md`, `privacyPolicySections` в `Shared/Strings.swift`,
  `AppStore/site/index.html`.
- **Сайт** правится в `AppStore/site/`, затем изменённые файлы копируются в `../METRO`
  (там лежит `CNAME` — не удалять) и пушатся уже оттуда.
- `.gitignore` — белый список корня: новый файл или папку в корне нужно разрешить явно.
- Репозиторий публичный: ключи `.p8`, `.p12`, профили подписи и идентификаторы ключей
  API не коммитим.

## Что не ломать

- Планировщик: одно правило `fill()`, стоянка принадлежит сегменту прибытия.
- Отсчёт рисует `Text(timerInterval:)`, приложение не обновляет его само — поэтому
  фоновые режимы не нужны.
- `waitShareOfHeadway = 0.25`: ожидание после пересадки сознательно занижено —
  предупреждение, пришедшее позже станции, хуже раннего.
- Файлы пользователя — с `completeUnlessOpen` и исключены из резервных копий.
- Осознанно нет аккаунтов, серверов, аналитики, рекламы и фоновых режимов: в анкете
  приватности честный ответ — «ничего не собираем».

## App Store

- На скриншотах никаких упоминаний цены, включая мелкий текст: «безкоштовно», «free»,
  скидки (отказ по 2.3.7, 24.08.2026).
- Название не менять в сторону «официального»; дисклеймер «Неофіційний застосунок»
  остаётся на видном месте.
- Воздушные тревоги выключены по умолчанию, источник назван неофициальным. Попросит
  App Review убрать — убираем.
- Архив и экспорт — `docs/READINESS.md`, «Шаг 3б», настройки — `AppStore/ExportOptions.plist`.
  Ключ API `.p8` лежит только в `~/.appstoreconnect/private_keys/`; если его нет —
  загружать через Xcode → Organizer.
