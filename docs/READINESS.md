## 2. Блокеры (без этого — не отправлять)

1. **PrivacyInfo.xcprivacy отсутствует в обоих таргетах.** `TripEngine` использует `UserDefaults`
   и компилируется и в приложение, и в виджет (подтверждено `nm` по бинарникам) → при загрузке
   ITMS-91053. Нужны два файла с `NSPrivacyAccessedAPICategoryUserDefaults` / `CA92.1`,
   регистрация в `gen_pbxproj.py` (APP_RES + новая Resources-фаза виджета).
2. **Политика конфиденциальности не размещена по публичному URL и не открывается из приложения**
   (Guideline 5.1.1). Плюс обязательные Support URL и Copyright в App Store Connect.
3. **Баг: «+1»/«−1» не работают после модельного прибытия** — ровно когда экран пишет
   «Ще їдете? Додайте зупинку: +1». `TripPlanner.replan` возвращает nil, потому что
   `nextEventIndex` после `arrivalDate` = nil. Фикс — одна строка (`?? events.count`).
   Воспроизведено в симуляторе.
4. **Баг: после kill приложения и истечения грейса Live Activity висит навсегда, поездка не
   попадает в журнал** (`TripEngine.restore()` только чистит defaults). Воспроизведено.
   Фикс — 3 строки (`endAllImmediately` + `TripLogStore.append` в restore).
5. **UX: контракт момента старта.** Нигде не сказано, что «Поїхали» надо жать в момент
   отправления поезда; нажатие на перроне сдвигает всё расписание на время ожидания.
   Решение без онбординга-каруселей: после выбора A и B — строка-превью маршрута
   «Академмістечко → Хрещатик · ~24 хв» + подсказка «Натисніть «Поїхали», коли поїзд
   рушить» + одноразовая карточка «Як це працює» (3 пункта).
6. **Платный Apple Developer Program** (организационно): Personal Team не может загружать
   в App Store Connect; там же вернуть Time Sensitive entitlement.

## 3. Высокий приоритет (до беты)

**Код**
- Нет `UNUserNotificationCenterDelegate` → при открытом приложении баннер/звук «Наступна —
  ваша» **не показывается вообще** (на заблокированном экране работает). Делегат с
  `willPresent → [.banner, .sound]` + локальная вибрация.
- GPS включается и на чисто подземных поездках (колбэк авторизации не проверяет
  `routeHasSurfaceStations`), не выключается, может показать промпт разрешения посреди
  тоннеля — противоречит purpose string и GPS.md.
- Пассивное самообучение может записать мусор: якорь с индексом 0 включает ожидание поезда
  в «ход перегона»; вычитается не та стоянка; нет фильтра свежести фикса (кэшированная
  позиция → снэп назад).
- Двойной тап «Поїхали» / старт при активной поездке не защищён; `ClosedRange` трап при
  `arrivalDate < startDate` (перевод часов + переплан на конечной).

**App Review / приватность**
- Политика и purpose string расходятся с фактом: калибровка теперь пишет все GPS-фиксы
  (`location.csv`) — описать в PRIVACY.md, purpose string, metadata; сделать запись
  motion/location в калибровке явным opt-in.
- Добавить `ITSAppUsesNonExemptEncryption=false`, `NSMotionUsageDescription` (страховка),
  `build-ios/` в .gitignore; экран «Про застосунок» (версия, политика офлайн + ссылка,
  контакт, дисклеймер «Неофіційний застосунок. Не пов'язаний з КП «Київський метрополітен»»,
  атрибуция «© OpenStreetMap contributors (ODbL)», источник данных — Портал відкритих даних Києва).
- Кнопки удаления локальных данных (журнал, калибровка) — 5.1.1 требует описать, как удалить.
- Чек-лист ASC: возрастная анкета (новая система), App Privacy «Data Not Collected»,
  статус трейдера DSA для EU, review notes с глоссарием украинских кнопок.

**UX**
- «Зупинити» — самая крупная и красная кнопка в 12 pt от ±1, без подтверждения, мгновенно
  убивает поездку/остров/уведомления → понизить вес, `confirmationDialog` или undo-тост;
  в состоянии прибытия — позитивное «Я на місці».
- ±1 непонятны → степпер у самого числа («Ще − 5 + зупинок») и/или тап по станции в списке
  «Поїзд зараз тут?»; те же подписи и тинт акцента в острове (`accessibilityLabel`).
- При B на другой линии нет обратной связи (заголовок «Тепер оберіть станцію призначення»
  застревает; «B» не виден на вкладке) → строка-превью с «1 пересадка (Театральна → Золоті ворота)».
- Лавина диалогов в момент отправления (пред-объяснение → системный запрос → GPS → «Дії
  наживо») → «Продовжити без сповіщень» вместо тупикового «Скасувати»; GPS спрашивать в спокойный момент.
- Тап по чипу «Останні поїздки» стартует поездку немедленно → чип только заполняет A/B;
  добавить «зворотна поїздка».
- Остров/экран красятся по разным линиям (остров — линия станции выхода, экран — текущий
  этап) → положить цвет текущего этапа в ContentState.
- Баннер «Сповіщення вимкнені» накладывается на заголовок и без кнопки «Відкрити Налаштування».

**Доступность (минимум)**
- `accessibilityLabel/Value/Hint` для вкладок линий, строк станций (A/B → «станція
  відправлення/призначення»), ±1 (в приложении и виджете), числа в острове; скрыть декор.
- Уважать `accessibilityReduceMotion` (сонар, дыхание, каскад, слайды).
- Цели ≥ 44 pt для ±1 и чипов; `@ScaledMetric` для таймера, `minimumScaleFactor` на строках.
- Состояние «одна зупинка» — не только цветом: текст «Наступна — ваша».
- Контраст: пройденные станции opacity 0.5 → 0.7; сегменты полосы в острове 22 % → 35–40 %;
  чипы 8 % → 14–16 %; красный текст 17 pt (4.31:1) — не использовать для мелкого текста.

**Данные**
- Модель не умеет «перегон закрыт / челнок» (в 2026 регулярные короткие закрытия после
  ударов; капремонт тоннеля Тараса Шевченка–Почайна не ранее 05.2027 с челноком до 23 мес.)
  → статус перегона в JSON + отказ строить маршрут через закрытый + чек-лист быстрого релиза данных.
- Во время воздушной тревоги поезда не ходят наземными участками → подсказка на маршрутах
  с наземными станциями.
- Пересадки: 300/360/300 с — правдоподобно днём; интервалы 2:45–3:30 пик / 5:30–6:30 межпик /
  7–11 вечер (официальная таблица) → ожидание по времени суток. Первый/последний поезд по
  станциям есть в том же официальном слое — дешёвая востребованная фича.

## 4. Средний / низкий приоритет

- Семантика alertDate при пересадке (стреляет при прибытии на станцию выхода — за 5–6 мин
  до «следующая — ваша» после перехода); соседние станции — alert через 1 с после старта;
  переплан повторно стреляет прошедшие уведомления; ±1 сдвигает на событие, а не на остановку.
- Персистентность: битые файлы молча заменяются; `trip_log.json` без предела; дубликат id
  в будущих данных уронит `Dictionary(uniqueKeysWithValues:)`.
- Калибровка: шит закрывается свайпом во время записи → `finish()` не вызван, теряется
  хвост буфера; экспорт шарит все сессии без выбора и размеров; сегмент линий без цветов.
- Виджет при `stopsRemaining==0` показывает «0 зупинок / 0:00» без состояния «прибули»;
  локскрин — таймер не прижат вправо; compact «трамвай + 10» читается неоднозначно.
- Журнал: метрики «🚶 1», «±1 · GPS 0» — для разработчика, не пассажира; нет очистки.
- Тексты: «Лук'янівська» с прямым апострофом (в JSON и на экране); «ти» на витрине vs «Ви»
  в приложении; «залишилась/залишилось» → «Ще 5 зупинок»; «доїхав» → «завершено»;
  «Станція: зупинився» → «Поїзд зупинився».
- Витрина: слайды 1–2 из одного скриншота с противоречивыми цифрами; слайд 3 режет кнопку;
  нет слайда с экраном блокировки (большинство iPhone в Украине — без острова).
- Иконка: кольцо на 4 сегмента при 3 линиях; «М в круге» близко к знаку КП → дисклеймер.
- Красный акцент = цвет M1 → на M2/M3 экранах читается как «ошибка»; рассмотреть нейтральный.
- Инженерия: ручные списки файлов в `gen_pbxproj.py` и дрейф с `project.yml`; нет
  `.gitignore` в репо; Swift 6 strict concurrency потребует `@MainActor` для стор.
- Английская локализация (все «Kyiv Metro» приложения — туристические, EN) — для роста.

## 5. Что сделано хорошо (честно)

- Планировщик чистый: единое правило `fill()`, dwell «принадлежит сегменту прибытия»
  согласован между планом, `replan`, калибровкой и генератором.
- Live Activity: состояние выводится в одном месте, дедуп по равенству, отсчёт ведёт
  `Text(timerInterval:)` — без фоновых режимов; уведомления запланированы заранее,
  переживают kill/ребут; грейс 10 мин, идемпотентная финализация.
- Дисциплина MainActor, `[weak self]`, атомарная запись JSON, DEBUG-хуки строго под `#if DEBUG`.
- Ноль сетевых вызовов и зависимостей — «Data Not Collected» корректно по определению Apple.
- Пред-объяснение перед запросом уведомлений; честное состояние «Ви на місці? / Мали
  прибути о …»; пересадка визуализирована понятно; правильные формы множественного числа.
- Единственное решение на рынке, работающее в тоннеле без GPS/сети + Live Activity + пересадки.

## 6.1. Данные: официальный график (коммит 61c1df1)

- **Времена всех 49 перегонов — из официального графика КП «Київський метрополітен»**
  (портал открытых данных Киева, слой `stopTimesUnderground`, секундная точность, медиана
  до 4 замеров на перегон). Контроль: Героїв Дніпра→Майдан = 15:50 при полевом факте ~16:04
  (было 14:04 по вики-времени, потом 15:58 после ручной правки). M2 конец-в-конец 36.1 мин
  (было 38.5), M3 43.3 (было 39.0 — модель занижала на 10 %), M1 39.0.

## 8. Тесты, которых нет (10 самых ценных)

1. `plan` по одной линии в обе стороны: число событий, монотонность времён, dwell только на
   промежуточных открытых, симметрия туда/обратно, закрытая промежуточная → isStop=false.
2. Гварды `plan`: from==to, закрытая from/to, неизвестный id → nil; пара без сегмента → seedTiming.
3. `plan` с пересадкой: ровно одно `isTransfer`, `arrival − prev.departure == walkSeconds`,
   уникальные stationId, from==exitAt / to==boardAt.
4. `replan(nextStopShift:)`: +1/−1 семантика, границы, **после arrivalDate +1 анкерит на count−2**.
5. `replan(anchoredAt:)`: инварианты для каждого anchor, dwell ⇔ isStop && !isTransfer.
6. Производные `ActiveTrip`: stopsRemaining, alertDate, nextStop, expiryDate.
7. `NotificationScheduler` как чистая функция: идентификаторы, ≤3, transfer-alert, нет
   запросов в прошлом кроме прибытия.
8. `ContentState(trip:now:)`: постоянен внутри перегона, меняется на arrival, Codable round-trip.
9. Бандл-JSON: уникальность id, сегменты для всех соседей, транзиты симметричны, bbox Киева,
   наземные пары ≥ 2×snapRadius, JSON == вывод генератора.
10. `CalibrationStore`/`timing`, `L10n.stopsWord` (1,2,5,11,12,21,22,25,111), `learn` как чистая функция.
