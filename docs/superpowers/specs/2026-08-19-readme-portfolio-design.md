# Портфолио-README для MetroTimer — дизайн

Дата: 19.08.2026. Статус: одобрено.

## Задача

Текущий `README.md` — инженерная инструкция на русском («Где что лежит»,
`xcodebuild`, генераторы). Для портфолио это неверный жанр: читатель должен за
полминуты понять, что это за продукт, а за три минуты — какую инженерную задачу
пришлось решить. Инструкция по сборке этой цели не служит и мешает.

## Решения

| Вопрос | Решение |
|---|---|
| Артефакт | `README.md` репозитория. GitHub Pages — отдельным шагом позже, с переиспользованием текстов |
| Язык | Английский |
| Подход | Кейс от задачи, но с галереей вверху для быстрого сканирования |
| Статус релиза | Отдельный честный раздел «Status» |

Ключевая ставка: раздел про ограничение (нет GPS, нет сети, нет фоновых
режимов) стоит **до** описания функций. Он превращает «ещё одно приложение с
таймером» в инженерную задачу и объясняет все последующие решения.

## Структура README

1. Заголовок, подзаголовок, герой-баннер `AppStore/screenshots/banner_real.png`
2. Бейджи: iOS 16.1+, Swift 5, SwiftUI, Live Activities, uk/en, pre-release
3. Галерея: 5 кадров из `AppStore/screenshots/framed/` в HTML-таблице
4. **The problem** — пассажир проезжает станцию
5. **The constraint** — нет GPS, нет сети, нет фоновых режимов; положение поезда
   надо вычислять, а не измерять
6. **How it works** — якорь в момент тапа, расписание считается вперёд,
   уведомления планируются сразу, `Text(timerInterval:)` переживает kill,
   Live Activity и App Intents, калибровка
7. **Where the numbers come from** — портал открытых данных Киева, вывод времён
   перегонов из времён отправления, медиана правдоподобных замеров
8. **What it can't know** — ожидание на пересадке, замирание счётчика в фоне
9. **Architecture** — таблица App / Shared / Widget, локализация парами
10. **Testing** — 28 тестов, что именно они держат
11. **Privacy** — ноль SDK, один опциональный запрос, защита файлов
12. **Status** — pre-release: готово / осталось / проверяется в поле
13. **Build** — три строки и ссылка на `docs/BUILD.md`
14. **Data, credits, disclaimer**

## Ограничения

- Никаких выдуманных метрик точности. Полевых данных пока нет, любая цифра
  вроде «±30 секунд» неподтверждаема.
- Изображения 1320×2868 вставляются через HTML с `width`, иначе разрывают
  страницу.
- `README.md` и `docs/` не входят в `project.pbxproj` — регенерация проекта
  не требуется.

## Что уезжает в `docs/BUILD.md`

Требования к окружению, `xcodebuild`, генераторы `gen_pbxproj.py` и
`gen_metro_json.py`, скрипты вывода официальных данных, отладочные хуки
`simctl`, слияние калибровок.
