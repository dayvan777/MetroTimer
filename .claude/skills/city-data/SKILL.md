# Данные города

Приложение считает всё из зашитого `App/Resources/kyiv_metro.json`. Город меняется без
предупреждения: с 10.09.2026 метро стало работать на час дольше, и неделю приложение пугало
«останнім поїздом» на час раньше реального. Этот скилл — чтобы второй раз так не было.

## 1. Сверка: изменилось ли что-то

```bash
cd "$SCRATCH"   # временная папка, не репозиторий
BASE="https://gisserver-stage.kyivcity.gov.ua/mayno/rest/services/KYIV_API/transport_public/MapServer"
curl -sA "Mozilla/5.0" "$BASE/13/query?where=1%3D1&outFields=*&f=json" -o stoptimes.json
curl -sA "Mozilla/5.0" "$BASE/14/query?where=1%3D1&outFields=*&f=json" -o intervals.json
python3 <repo>/Scripts/derive_official_service.py intervals.json stoptimes.json > service.txt
python3 <repo>/Scripts/derive_official_times.py stoptimes.json > times.txt
```

Без `User-Agent` браузера сервер отдаёт HTML. Сравнить напечатанные литералы с
`OFFICIAL_HEADWAYS`, `OFFICIAL_SERVICE` и сегментами в `Scripts/gen_metro_json.py`.
Совпало — записать дату сверки в ответ пользователю и остановиться.

Открытые данные отстают от жизни и не знают про тревоги. Поэтому дополнительно искать
новости за период с последней сверки: «київський метрополітен графік», «комендантська
година Київ», «метро під час тривоги», закрытие станций и вестибюлей. Источник фактов —
метрополитен и КМДА; пересказы СМИ сверять между собой.

## 2. Обновление

1. Вставить новые литералы в `Scripts/gen_metro_json.py`, обновить дату в докстринге.
2. `python3 Scripts/gen_metro_json.py` → `App/Resources/kyiv_metro.json`.
3. Обновить ожидания в `Tests/ScheduleTests.swift` и `Tests/DataTests.swift`, прогнать тесты.
4. Записать изменение в `docs/FEEDBACK.md` («Изменения в городе…») и в память проекта.

## Ловушки, на которые уже наступали

- **Полночь.** Последние поезда после 00:00 источник отдаёт как секунды нового дня
  (00:11:05 → 665). `derive_official_service.py` сдвигает их на +86400, если `last < first`.
  Служебные сутки в `MetroRepository` начинаются в 03:00, час < 3 читается как час + 24.
- **Часовой пояс Mac — не Киев.** Сверять «сейчас» по `Europe/Kyiv`, не по системным часам.
- **Порог теста ожидания на пересадке** зависит от официальных интервалов: сейчас +45 с
  между часом пик и вечером. Упал после обновления данных — сначала посмотреть числа.
- **Наземная ≠ «isSurface по ощущению».** Видубичі подземная (8 м). Флаг `isSurface` — про
  GPS-привязку; что стоит при тревоге — отдельное поле `alertStop` на перегоне.
- Поезда из депо с середины линии дают выбросы во временах перегонов; скрипт берёт медиану
  правдоподобных (60–420 с) — не «чинить» выбросы руками.

## Правила тревог (с 10.09.2026)

`ALERT_STOPS` в `Scripts/gen_metro_json.py`: `"any"` — перегон стоит при любой тревоге
(М1 Арсенальна–Лісова), `"red"` — только при красной (М3 Видубичі–Славутич). Уровень тревоги
приложение пока не знает (`AlertService.level` всегда `nil`): источник отдаёт только «є/немає».
Изменились правила — править словарь, тексты `alertRouteWarning` / `alertsActiveTrip` /
`aboutAlertFAQBody` в `Shared/Strings.swift` и тест `testAlertRulesFollowKmdaFromSeptember2026`.
